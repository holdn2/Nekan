Request account and data deletion

Nekan · Home · Privacy policy

If you still have the app, you do not need this page. Settings (⚙) → Delete account does it there and then. This page is for when you have already uninstalled the app or cannot reach that screen.

How to ask

Send an email to {{CONTACT_EMAIL}} with just these two things.

  • Subject — Nekan account deletion request
  • Body — the email address of the Google account you signed up with. So that it can be verified as yours, send it from that address.

What gets deleted

  • The account and every task held on the server, text and notes and due dates included
  • Syncing with your other devices stops
  • It cannot be undone.

Tasks already on a device stay in that device's own file. Deleting the server copy does not empty the list in an app that is already installed. To clear that too, uninstall the app or delete the tasks inside it.

How long it takes

Requests are handled within a few business days and the result is sent back to the same address. A request that cannot be verified as yours cannot be acted on, so please write from the address you signed up with.
