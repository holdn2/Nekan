# Nekan

아이젠하워 매트릭스 데스크톱 위젯. Electron 기반, Windows용.
Claude 계열의 밝은 베이지 테마 + 다크 테마를 지원합니다.

이름은 네 칸(4분면)에서 왔습니다. 앱 안팎에서 표기는 `Nekan` 하나로 통일합니다.

## 설치

[Releases](https://github.com/holdn2/Nekan/releases)에서 최신 `Nekan-Setup-x.y.z.exe`를 받아 실행하면 됩니다.
클릭 한 번으로 끝나고 **관리자 권한을 묻지 않습니다** — 내 계정 폴더에만 설치되기 때문입니다.
설치가 끝나면 바탕화면과 시작 메뉴에 **Nekan** 바로가기가 생깁니다.

> 코드 서명을 아직 하지 않아서 Windows SmartScreen이 "PC를 보호했습니다" 경고를 띄웁니다.
> **추가 정보 → 실행**을 누르면 설치됩니다.

## 업데이트

**따로 할 일이 없습니다.** 앱이 켜져 있는 동안 알아서 새 버전을 확인하고 백그라운드로 받아둡니다.
받아둔 버전은 **앱을 닫을 때 저절로 적용**되므로, 신경 쓰지 않아도 다음에 켤 때는 최신입니다.

기다리기 싫으면 타이틀바에 나타나는 <b>↑</b> 버튼(또는 함께 뜨는 알림의 **지금 재시작**)을 누르면
그 자리에서 재시작하며 적용합니다. **이 버튼은 받아둔 버전이 있을 때만 보입니다** — 보이지 않는다면
이미 최신이거나 아직 받는 중입니다. 확인에 실패해도(네트워크 없음 등) 아무 것도 뜨지 않습니다.

할 일 데이터는 설치 폴더가 아니라 `%APPDATA%\Nekan`에 있어서 업데이트해도 그대로 남습니다.

**지금 몇 버전인지는 타이틀바의 앱 이름 옆**에 작게 적혀 있습니다 (바 모드에서는 앱 이름과 함께
빠지므로 바 폭에는 영향이 없습니다).

**[가이드 탭](#가이드-탭) 맨 아래**에는 버전과 함께 업데이트 상태(`최신 버전입니다` ·
`새 버전을 받는 중…` · `준비됨`), 릴리스 노트 링크가 있습니다. 확인에 **실패했을 때는 아무 말도
하지 않습니다** — 확인을 못 했는데 "최신"이라고 하는 게 제일 나쁜 거짓말이라서요.

## 실행 방법 (개발)

```powershell
npm install   # 최초 1회
npm start
npm test      # 저장·정규화·날짜 로직 단위 테스트 (선택)
```

**설치 파일 빌드**

```powershell
npm run dist      # dist\Nekan-Setup-1.0.0.exe — 로컬 확인용, 업로드하지 않음
npm run release   # 빌드 + GitHub Release에 업로드 (GH_TOKEN 필요)
```

**릴리스 절차**

1. `package.json`의 `version`을 올리고 커밋한다.
2. `npm run release` — electron-builder가 설치 파일과 `latest.yml`을 만들어
   해당 버전의 **draft** Release로 올린다.
3. GitHub에서 그 Release를 **publish**한다. 설치된 앱들은 이때부터 새 버전을 보게 된다.

`latest.yml`이 곧 업데이트 피드다. 설치 파일만 따로 올리면 아무도 업데이트되지 않는다.

> **electron-builder는 같은 태그로 draft를 두 개 만든다.** 업로드가 병렬로 돌면서 둘 다
> "릴리스가 없네"라고 판단해 각자 만드는 경쟁 상태이고, v1.0.0과 v1.0.1 **두 번 다** 이렇게
> 갈렸다(매번 `.blockmap`이 혼자 떨어져 나갔다). 그래서 `npm run release`가 끝에
> `tools/check-release.js`를 돌려 **자동으로 합치고 파일 세 개를 확인한다.** 손댈 것은 없고,
> 뭔가 빠지면 종료 코드로 알려준다.
>
> 갈린 채로 publish하면 조용히 망가진다: `latest.yml`이 없는 쪽을 올리면 아무도 업데이트되지
> 않고, `.blockmap`이 없는 쪽을 올리면 모두가 매번 100MB를 통째로 받는다.

## 기능

### 업무 / 일상 매트릭스

타이틀바의 **`업무` / `일상` 토글**로 매트릭스를 두 벌 나눠 씁니다. 퇴근하고 나서 회사 할 일이 눈에 밟히지 않게, 반대로 업무 중에 개인 일이 섞이지 않게 하려는 기능입니다.

- **4분면·히스토리·휴지통·개수 칩·내보내기가 모두 선택한 쪽만** 보여줍니다. 즉 토글은 매트릭스만이 아니라 앱 전체의 모드입니다.
- **딱 하나 예외가 [다 꺼내기](#다-꺼내기-매트릭스-위-목록)입니다.** 이 목록은 양쪽이 함께 쓰고, 그래서 헤더에 `공유` 표시가 붙어 있습니다.
- **어느 쪽인지는 분면으로 내리는 순간 정해집니다.** 다 꺼내기에 있는 동안에는 아직 업무도 일상도 아니고, 지금 보고 있는 매트릭스로 끌어내리면 그때 그쪽 소속이 됩니다.
- 반대로 **분면의 항목을 다 꺼내기로 끌어올리면 소속이 풀립니다.** 그래서 업무 항목을 위로 올린 뒤 일상 쪽에서 내려받으면 **반대편으로 옮길 수 있습니다.**
- 선택한 쪽은 종료 후에도 유지되고, **바 모드에서도 토글이 그대로** 보입니다.
- 두 매트릭스는 **한 파일에 같이 저장됩니다** (항목마다 소속이 붙는 방식). 백업할 파일이 늘어나지 않습니다.

### 창 모드

| 버튼  | 동작                                                                   |
| ----- | ---------------------------------------------------------------------- |
| ⤓     | **내보내기** (PDF · HTML · Markdown) — 아래 [내보내기](#내보내기) 참고 |
| ☀ / ☾ | **라이트 ↔ 다크 테마 전환** (선택값 저장됨)                            |
| 📌    | 항상 위에 고정 on/off                                                  |
| ▭     | **바 모드 ↔ 확장 모드** 전환 (600×48 바 ↔ 전체 UI)                     |
| —     | 작업표시줄로 최소화                                                    |
| ✕     | 앱 완전히 종료                                                         |

- 타이틀바를 드래그해서 창을 옮길 수 있고, **더블클릭**해도 바 모드가 토글됩니다.
- 바 모드에는 **아이콘 · `업무`/`일상` 토글 · 분면별 남은 개수 · 창 버튼**이 들어갑니다. 개수 칩을 클릭하면 다시 펼쳐지고, 토글은 바인 채로도 눌러서 전환할 수 있습니다 (개수도 선택한 쪽 기준으로 다시 셉니다).
- 바에서 빠지는 건 **앱 이름 텍스트와 내보내기 버튼**뿐입니다. 바 크기는 **600×48**이고, 토글이 들어가면서 기존 440px로는 창 버튼이 밀려나 넓혔습니다 (`Ctrl` + `E`는 확장 모드에서만).
- **바를 옮긴 자리에서 그대로 펼쳐집니다.** 바를 화면 오른쪽에 붙여 두었다면 펼칠 때 오른쪽 끝을 맞춰 왼쪽으로 열리므로 화면 밖으로 나가지 않고, 그 창을 다시 접으면 바가 원래 있던 자리로 돌아옵니다.
- 창 위치·크기·모드·테마·고정 여부는 종료 후에도 유지됩니다. **바 상태로 종료하면 다음 실행에서도 바가 있던 자리에서 열립니다.**

### 다 꺼내기 (매트릭스 위 목록)

분류하기 전에 머릿속에 있는 걸 일단 전부 쏟아내는 공간입니다. 매트릭스 바로 위에 있습니다.

**업무·일상 매트릭스가 함께 쓰는 유일한 목록입니다** (헤더의 `공유` 표시). 떠오른 걸 적을 때는 어느 쪽 일인지 고르지 않아도 되고, 나중에 분면으로 내릴 때 그쪽 소속이 됩니다.

- 헤더의 **`다 꺼내기`를 클릭**하면 펼쳐지고, 다시 누르면 접힙니다. 접힘/펼침은 종료 후에도 유지됩니다.
- 입력창에 적고 Enter — 입력창이 비워지므로 **계속 이어서 적을 수 있습니다**.
- 메모장·메신저에서 **여러 줄을 복사해 붙여넣으면 줄마다 항목 하나씩**으로 쪼개집니다. 앞에 붙은 `-` `*` `1.` 같은 목록 기호와 빈 줄은 알아서 걸러집니다 (한 번에 최대 100줄).
- 여기 있는 항목을 **아래 분면으로 드래그**하면 그때 분류가 됩니다. 반대로 분면의 항목을 **다시 끌어올릴 수도** 있고(접혀 있으면 헤더에 떨어뜨리면 됩니다), 목록 안에서 순서도 바꿀 수 있습니다.
- 항목은 **더블클릭으로 수정**, `×` 로 휴지통으로 보냅니다.
- 목록이 길어져도 **매트릭스를 밀어내지 않습니다.** 정해진 높이까지만 자라고 그 다음부터는 목록 안에서 스크롤됩니다.
- 마감일·메모·완료 체크는 **분면으로 내린 뒤에** 쓸 수 있습니다. 꺼내는 단계에서는 문구만 적으면 됩니다.
- 아직 분류하지 않은 항목이 있으면 **바 모드에서도 개수 칩**(속이 빈 동그라미)이 나타납니다. 비어 있으면 칩도 사라집니다.

### 매트릭스 탭

- 4분면: **Urgent&Important / Important&안Urgent / Urgent&안Important / 둘 다 아님**
- 각 분면 하단 입력창에 입력 후 Enter 또는 `+` 로 추가
- 목록의 각 항목 앞에 **분면별 순번**이 표시됩니다 (드래그로 순서를 바꾸면 번호도 다시 매겨짐)
- 항목 위에 마우스를 올리면 나타나는 `×` 로 삭제 → **휴지통으로 이동**
- 왼쪽 **동그라미를 클릭하면 완료** 처리되어 목록에서 사라지고 히스토리로 이동
- 항목 **더블클릭 → 내용 수정** (Enter 저장, Esc 취소)
- 항목 **클릭 → 메모 패널 열기** (아래 [메모](#메모) 참고)
- 항목을 **드래그해서 다른 분면으로 이동**하거나 같은 분면 안에서 순서 변경
- **1분면이 5개를 넘으면 개수 표시가 붉어집니다.** 급한 일만 쫓고 있다는 신호이고, 대개 2분면을 미뤄둔 결과입니다 ([가이드 탭](#가이드-탭) 참고). **막지는 않습니다** — 할 일을 못 적게 하면 그게 다시 머릿속으로 들어가니까요. 다른 분면에는 이 표시가 없습니다. 2분면이 차 있는 것은 오히려 잘하고 있다는 뜻입니다

### 분면 크기 조절

- 별도의 조절 바 없이 **분면의 경계(엣지)를 그대로 드래그**합니다.
- 가로·세로 경계선은 4분면이 공유합니다: 1분면 너비를 늘리면 2분면이 줄고(3·4분면도 같이 움직임), 1분면 높이를 늘리면 3·4분면 높이가 줄어듭니다.
- 가운데 **교차점**을 잡으면 가로·세로를 한 번에 조절할 수 있습니다.
- 경계를 **더블클릭**하면 반반으로 초기화됩니다. 조절한 비율은 종료 후에도 유지됩니다.

### 마감 날짜

- 입력창 옆의 **달력 버튼**으로 추가할 때 바로 마감일을 지정할 수 있습니다.
- 이미 있는 항목은 오른쪽 **날짜 칩을 클릭**하면 달력이 열리고, 옆의 `×` 로 날짜를 지웁니다.
- 남은 기간에 따라 색이 바뀝니다: **지남**(빨강) / **오늘**(주황) / **3일 이내**(노랑) / 그 이후(회색)
- 앱을 며칠 켜둬도 **자정이 지나면 색과 남은 일수가 알아서 갱신**됩니다.
- 히스토리·휴지통 목록에서도 마감일이 함께 보입니다.

### 메모

- 항목을 **클릭**하면 매트릭스 아래에 메모 패널이 열립니다. 할 일 하나당 메모 하나입니다.
- 패널이 열려도 **분면 크기는 그대로**입니다. 매트릭스를 눌러 담는 대신 창 높이가 그만큼 늘어나고, 닫으면 다시 줄어듭니다. (화면에 여유가 없으면 늘어나는 만큼만 반영됩니다.)
- 메모가 없는 항목은 바로 입력 상태로 열립니다. `Ctrl` + `Enter` 저장, `Esc` 취소.
- 저장된 메모는 **더블클릭**하면 다시 수정할 수 있고, `삭제` 로 메모만 지웁니다(할 일은 그대로).
- 메모가 있는 항목에는 **메모 아이콘**이 붙고, 아이콘에 마우스를 올리면 내용이 미리 보입니다.
- 히스토리·휴지통에서는 메모가 항목 아래에 **읽기 전용**으로 함께 보입니다. 길면 두 줄까지만 보이고, **클릭하면 전체가 펼쳐집니다**(다시 클릭하면 접힘). 이 두 탭에서는 메모를 고치거나 지울 수 없고, 휴지통에서 복원하면 메모도 그대로 돌아옵니다.
- 다시 클릭하거나 `✕`, 다른 탭으로 이동, 바 모드 전환 시 패널이 닫히며 늘어났던 높이를 되돌려 줍니다.
- 최대 2000자까지 저장되며, 내용은 할 일과 함께 `data.json`에 남습니다.

### 내보내기

지금 화면에 있는 **다 꺼내기 + 4분면**을 파일로 저장합니다. 회의 자료로 붙이거나 인쇄해서 벽에 붙여둘 때 씁니다.

**지금 선택한 쪽(업무 또는 일상)만** 나갑니다. 문서 제목과 기본 파일명에 어느 쪽인지 들어가고(`Nekan 업무 2026-08-02.pdf`), 다 꺼내기는 공유라 양쪽 문서에 모두 들어갑니다. 둘 다 필요하면 토글을 바꿔 한 번 더 내보내면 됩니다.

- 타이틀바의 **⤓ 버튼** 또는 `Ctrl` + `E` → 저장 위치를 묻는 창이 뜹니다.
- 창 아래쪽 **파일 형식**을 골라 형식을 정합니다:
  - **PDF** — A4 가로 한 장. 인쇄·공유용 (기본값)
  - **HTML** — 브라우저로 바로 열리는 파일 하나. 외부 파일을 전혀 참조하지 않아 그대로 보내도 됩니다
  - **Markdown** — 노션·깃허브·메모장에 붙여넣기 좋은 텍스트
- 내용은 **분면 제목 · 순번 · 할 일 · 마감일(남은 일수 포함) · 메모**까지 목록 그대로 나갑니다. 비어 있는 분면도 `비어 있음`으로 표시되어 4분면 구성이 유지됩니다.
- **완료 항목과 휴지통은 포함되지 않습니다.** 지금 살아 있는 할 일만 나갑니다.
- 저장하면 아래에 알림이 뜨고, `폴더 열기` 로 저장한 위치를 바로 열 수 있습니다.
- PDF는 항상 **라이트 팔레트**로 만들어집니다 (다크 테마로 인쇄하면 검은 판이 되므로).
- 할 일이 하나도 없으면 저장하지 않고 안내만 표시합니다. 바 모드에서는 버튼이 숨겨집니다.

### 히스토리 탭

- **지금 선택한 매트릭스(업무/일상)의 기록만** 보입니다. 탭 옆 개수 배지도 그쪽 기준입니다
- 완료한 항목을 날짜별로 묶어서 최신순 표시 (완료 시각, 원래 분면 색상 포함)
- 날짜 그룹 안에서 번호가 1번부터 매겨집니다
- 검색창으로 필터링. **검색은 항상 기록 전체를 뒤집니다** — 화면에 그려진 것만 찾는 것이 아니라서, 한참 전에 완료한 항목도 바로 나옵니다
- **한 번에 100개까지만 그리고, 그보다 많으면 목록 끝에 `더 보기 (N개 남음)`가 나타납니다.** 목록이 길어져도 검색창에 글자를 칠 때마다 끊기지 않게 하려는 것이고, **항목이 지워지는 것은 아닙니다.** 탭을 옮겼다 오거나 검색어를 바꾸면 다시 100개부터 시작합니다
- `되돌리기` → 원래 분면으로 복귀 / `삭제` → 휴지통으로 이동
- `전체 휴지통으로` → 완료 항목 전체를 휴지통으로 이동

### 휴지통 탭

- 삭제한 항목은 바로 지워지지 않고 휴지통에 남아 **되돌릴 수 있습니다**.
- 히스토리와 마찬가지로 **선택한 매트릭스 것만** 보입니다. 단 분류하기 전에 다 꺼내기에서 바로 지운 항목은 소속이 없어서 **양쪽 휴지통에 모두** 나타납니다. `휴지통 비우기`도 화면에 보이는 것만 지웁니다.
- 삭제한 날짜별로 묶여서 최신순으로 표시되고, 검색창으로 필터링할 수 있습니다. 히스토리와 마찬가지로 한 번에 100개까지 그리고 나머지는 `더 보기`로 이어집니다.
- `복원` → 원래 자리로 (완료 상태였다면 히스토리로) 복귀 / `영구 삭제` → 완전히 제거
- `전체 복원` / `휴지통 비우기` 로 한 번에 처리할 수 있습니다 (비우기는 되돌릴 수 없음)
- 영구 삭제한 항목은 앱 어디에도 다시 나타나지 않지만, **내용을 지운 표시만 90일 동안 파일에 남습니다.** 나중에 여러 기기에서 같이 쓸 때 지운 항목이 되살아나지 않게 하기 위한 것이고, 제목과 메모는 삭제 즉시 지워집니다.

### 가이드 탭

- 아이젠하워 매트릭스 프레임워크 설명 (중요도·긴급도 두 축, 네 분면의 의미와 예시)
- 쓰는 순서, 기억할 원칙, 이 앱의 기능과 연결되는 팁까지 정리된 읽기 전용 문서
- **맨 아래에 실행 중인 버전과 업데이트 상태**, 릴리스 노트 링크가 있습니다 (링크는 기본 브라우저로 열립니다)
- 내용은 `src/renderer/index.html` 의 `#guideView` 에 정적 마크업으로 들어 있습니다

## 아이콘

`build\icon.ico` (16~256px 멀티 사이즈)가 exe·작업표시줄·타이틀바 로고에 모두 쓰입니다.
디자인을 바꾸고 싶으면 색상만 고쳐서 다시 생성하면 됩니다.

```powershell
powershell -ExecutionPolicy Bypass -File tools\make-icon.ps1
```

## 데이터 저장 위치

```
%APPDATA%\Nekan\data.json
```

이름이 바뀌기 전 폴더(`EisenhowerMatrix`, 그 전의 `eisenhower-matrix`)에 데이터가 있으면
**처음 실행할 때 한 번 복사해 옵니다.** 옛 폴더는 그대로 남으니 확인한 뒤 지우면 됩니다.

할 일(마감일·메모 포함)과 완료 기록, 휴지통 항목, 창·테마 설정이 모두 이 파일에 JSON으로 저장됩니다.
**업무·일상 매트릭스도 파일이 갈리지 않습니다** — 항목마다 어느 쪽인지가 붙어 있고(다 꺼내기 항목은 비어 있음), 지금 보고 있는 쪽만 설정에 기록됩니다.
저장은 임시 파일에 쓴 뒤 rename 하는 방식이라 중간에 끊겨도 파일이 깨지지 않습니다.
백업하려면 이 파일만 복사하면 됩니다.
