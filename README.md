# Eisenhower Matrix (Desktop Widget)

아이젠하워 매트릭스 데스크톱 위젯. Electron 기반, Windows용.
Claude 계열의 밝은 베이지 테마 + 다크 테마를 지원합니다.

## 실행 방법

**개발/일반 실행**

```powershell
npm install   # 최초 1회
npm start
npm test      # 저장·정규화·날짜 로직 단위 테스트 (선택)
```

**포터블 exe 빌드**

```powershell
npm run dist            # dist\EisenhowerMatrix 1.0.0.exe (설치 불필요)
npm run dist:installer  # NSIS 설치 파일이 필요할 때
```

바탕화면의 **EisenhowerMatrix** 바로가기로 바로 실행할 수 있습니다.

## 기능

### 창 모드

| 버튼  | 동작                                               |
| ----- | -------------------------------------------------- |
| ☀ / ☾ | **라이트 ↔ 다크 테마 전환** (선택값 저장됨)        |
| 📌    | 항상 위에 고정 on/off                              |
| ▭     | **바 모드 ↔ 확장 모드** 전환 (440×48 바 ↔ 전체 UI) |
| —     | 작업표시줄로 최소화                                |
| ✕     | 앱 완전히 종료                                     |

- 타이틀바를 드래그해서 창을 옮길 수 있고, **더블클릭**해도 바 모드가 토글됩니다.
- 바 모드에서는 4분면별 남은 개수만 표시되며, 개수 칩을 클릭하면 다시 펼쳐집니다.
- 창 위치·크기·모드·테마·고정 여부는 종료 후에도 유지됩니다.

### 매트릭스 탭

- 4분면: **Urgent&Important / Important&안Urgent / Urgent&안Important / 둘 다 아님**
- 각 분면 하단 입력창에 입력 후 Enter 또는 `+` 로 추가
- 목록의 각 항목 앞에 **분면별 순번**이 표시됩니다 (드래그로 순서를 바꾸면 번호도 다시 매겨짐)
- 항목 위에 마우스를 올리면 나타나는 `×` 로 삭제 → **휴지통으로 이동**
- 왼쪽 **동그라미를 클릭하면 완료** 처리되어 목록에서 사라지고 히스토리로 이동
- 항목 **더블클릭 → 내용 수정** (Enter 저장, Esc 취소)
- 항목 **클릭 → 메모 패널 열기** (아래 [메모](#메모) 참고)
- 항목을 **드래그해서 다른 분면으로 이동**하거나 같은 분면 안에서 순서 변경

### 분면 크기 조절

- 별도의 조절 바 없이 **분면의 경계(엣지)를 그대로 드래그**합니다.
- 가로·세로 경계선은 4분면이 공유합니다: 1분면 너비를 늘리면 2분면이 줄고(3·4분면도 같이 움직임), 1분면 높이를 늘리면 3·4분면 높이가 줄어듭니다.
- 가운데 **교차점**을 잡으면 가로·세로를 한 번에 조절할 수 있습니다.
- 경계를 **더블클릭**하면 반반으로 초기화됩니다. 조절한 비율은 종료 후에도 유지됩니다.

### 마감 날짜

- 입력창 옆의 **달력 버튼**으로 추가할 때 바로 마감일을 지정할 수 있습니다.
- 이미 있는 항목은 오른쪽 **날짜 칩을 클릭**하면 달력이 열리고, 옆의 `×` 로 날짜를 지웁니다.
- 남은 기간에 따라 색이 바뀝니다: **지남**(빨강) / **오늘**(주황) / **3일 이내**(노랑) / 그 이후(회색)
- 앱을 며칠 켜둬도 **자정이 지나면 색과 남은 일수가 알아서 갱신**됩니다.
- 히스토리·휴지통 목록에서도 마감일이 함께 보입니다.

### 메모

- 항목을 **클릭**하면 매트릭스 아래에 메모 패널이 열립니다. 할 일 하나당 메모 하나입니다.
- 패널이 열려도 **분면 크기는 그대로**입니다. 매트릭스를 눌러 담는 대신 창 높이가 그만큼 늘어나고, 닫으면 다시 줄어듭니다. (화면에 여유가 없으면 늘어나는 만큼만 반영됩니다.)
- 메모가 없는 항목은 바로 입력 상태로 열립니다. `Ctrl` + `Enter` 저장, `Esc` 취소.
- 저장된 메모는 **더블클릭**하면 다시 수정할 수 있고, `삭제` 로 메모만 지웁니다(할 일은 그대로).
- 메모가 있는 항목에는 **메모 아이콘**이 붙고, 아이콘에 마우스를 올리면 내용이 미리 보입니다.
- 히스토리·휴지통에서는 메모가 항목 아래에 **읽기 전용**으로 함께 보입니다. 길면 두 줄까지만 보이고, **클릭하면 전체가 펼쳐집니다**(다시 클릭하면 접힘). 이 두 탭에서는 메모를 고치거나 지울 수 없고, 휴지통에서 복원하면 메모도 그대로 돌아옵니다.
- 다시 클릭하거나 `✕`, 다른 탭으로 이동, 바 모드 전환 시 패널이 닫히며 늘어났던 높이를 되돌려 줍니다.
- 최대 2000자까지 저장되며, 내용은 할 일과 함께 `data.json`에 남습니다.

### 히스토리 탭

- 완료한 항목을 날짜별로 묶어서 최신순 표시 (완료 시각, 원래 분면 색상 포함)
- 날짜 그룹 안에서 번호가 1번부터 매겨집니다
- 검색창으로 필터링
- `되돌리기` → 원래 분면으로 복귀 / `삭제` → 휴지통으로 이동
- `전체 휴지통으로` → 완료 항목 전체를 휴지통으로 이동

### 휴지통 탭

- 삭제한 항목은 바로 지워지지 않고 휴지통에 남아 **되돌릴 수 있습니다**.
- 삭제한 날짜별로 묶여서 최신순으로 표시되고, 검색창으로 필터링할 수 있습니다.
- `복원` → 원래 자리로 (완료 상태였다면 히스토리로) 복귀 / `영구 삭제` → 완전히 제거
- `전체 복원` / `휴지통 비우기` 로 한 번에 처리할 수 있습니다 (비우기는 되돌릴 수 없음)

### 가이드 탭

- 아이젠하워 매트릭스 프레임워크 설명 (중요도·긴급도 두 축, 네 분면의 의미와 예시)
- 쓰는 순서, 기억할 원칙, 이 앱의 기능과 연결되는 팁까지 정리된 읽기 전용 문서
- 내용은 `src/renderer/index.html` 의 `#guideView` 에 정적 마크업으로 들어 있습니다

### 단축키

| 키             | 동작                        |
| -------------- | --------------------------- |
| `Ctrl` + `M`   | 바 모드 ↔ 확장 모드         |
| `Ctrl` + `D`   | 라이트 ↔ 다크 테마          |
| `Ctrl` + `1~4` | 해당 분면 입력창으로 포커스 |
| `Enter`        | 항목 추가 / 수정 저장       |
| `Ctrl` + `Enter` | 메모 저장                 |
| `Esc`          | 수정 취소 / 메모 편집 취소  |

## 아이콘

`build\icon.ico` (16~256px 멀티 사이즈)가 exe·작업표시줄·타이틀바 로고에 모두 쓰입니다.
디자인을 바꾸고 싶으면 색상만 고쳐서 다시 생성하면 됩니다.

```powershell
powershell -ExecutionPolicy Bypass -File tools\make-icon.ps1
```

## 데이터 저장 위치

```
%APPDATA%\EisenhowerMatrix\data.json
```

할 일(마감일·메모 포함)과 완료 기록, 휴지통 항목, 창·테마 설정이 모두 이 파일에 JSON으로 저장됩니다.
저장은 임시 파일에 쓴 뒤 rename 하는 방식이라 중간에 끊겨도 파일이 깨지지 않습니다.
백업하려면 이 파일만 복사하면 됩니다.

## 구조

```
build/icon.ico         # exe / 작업표시줄 아이콘
tools/make-icon.ps1    # 아이콘 생성 스크립트
src/
  main.js              # 메인 프로세스: 창 모드 전환, 저장, IPC
  preload.js           # contextBridge 기반 IPC 브리지
  assets/icon.*        # 런타임에서 쓰는 아이콘 사본
  shared/
    core.js            # 날짜·정규화·레이아웃 비율 (메인·렌더러·테스트 공용)
    store-io.js        # data.json 읽기/쓰기 (temp write + rename)
  renderer/
    index.html
    styles.css         # 라이트/다크 팔레트 (data-theme)
    renderer.js        # 상태 관리, 렌더링, 드래그앤드롭, 테마
test/                  # node --test 단위 테스트
```
